
# Java Calculator Application

## Project Description
A Java-based calculator application that performs basic arithmetic operations.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Calculation history
- Clear history
- Division by zero error handling

## Technologies Used
- Java
- Scanner
- ArrayList
- Switch statements
- Conditional statements

## How to Run

1. Install Java JDK.
2. Download Calculator.java.
3. Open the terminal.
4. Compile the program:

javac Calculator.java

5. Run the program:

java Calculator
